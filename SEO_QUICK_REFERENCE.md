## 🆘 If Something Breaks

**Error on homepage?**
- Clear `.next` cache: `rm -rf .next`
- Rebuild: `npm run build`
- Check imports in `pages/index.tsx`

**SEOHead component not found?**
- Verify file exists: `components/SEOHead.tsx`
- Check import path is correct
- Rebuild project

**Sitemap not accessible?**
- Check: https://tetherlink.io/sitemap.xml
- Verify `public/sitemap.xml` exists
- Check `next.config.js` has rewrite rule
